An AI-powered plugin that makes WordPress documentation easier to navigate.
Created for a UX/UI class focused on designing interactions // January 2025 - May 2025.
Group Members: Katie Fischer, Christian Valentino, & Harrison Levine.

The Problem

WordPress powers nearly half the web, but its official documentation is often outdated, overly technical, or hard to navigate. This slows down user momentum and leads to frustration.

DocuBot is our solution: a browser-based AI assistant that blends official docs with community knowledge and delivers step-by-step help in plain language—with real-world code snippets.

My Team Contributions

  • Led user research via surveys and interviews
  • Wrote and refined our “How Might We” statement
  • Created high-fidelity Figma wireframes and final prototype
  • Produced the project’s demo video and portfolio content

What Worked Well

  • The chat interface helped users feel more confident asking for help
  • Combining community knowledge with official docs made answers more practical

What We’d Improve

  • Streamline the onboarding process for first-time users
  • Add fallback suggestions when no clear documentation exists

Future Ideas

  • Turn DocuBot into a real WordPress plugin
  • Allow users to ask coding questions inside a live code sandbox
  • Add multi-language support and accessibility features
